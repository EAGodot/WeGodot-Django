

# 我們是誰

不去想太多飄渺的事情(各種起源論述)，立足當下：我們已存在地球數百萬年。這不是生物學意義上的「智人」年齡，而是我們對自身文明前史的追溯——從使用第一件工具、留下第一處岩畫、點燃第一堆不滅的火種開始，我們就在成為「我們」。

宇宙（基本法則，基本物質）賦予這顆星球的屬性/行爲孕育了我們的行爲種種。他的晝夜分明，山川溝壑，天氣四時，這些不是文明的背景，而是文明的語法。這些語法的約束在我們行爲有了各異的表達（地理差異，文化差異，各地區的發展，宗教文化），因爲地球如此，所以我們如此。

地球存在的時間比我們久的多，它在它存在時間裏持續的演變，不停的變換表達。當下的我們是它想要表達的一部分，還包括它的所有實體，奔湧的河流，凜冽的寒風，皚皚白雪，蒼蒼山野...還有冷暖各自知的野生動物。

有我們以來，自然環境是讓人滿足的，土壤，河流，空氣等等合適的條件，不停的促進著人類族群的在自然世界中的發展。憑藉著天時地利人和，在歷史必然的一段時期我們逐漸越來越脫離茹毛飲血的生存狀態，我們不在那麽依賴捕獵野生動物，采集野果野草，提防野獸來襲來維持族群延續。我們主要吃食自己飼養的牲畜，我們采摘自己種植的果實，我們的生存與野生世界關聯越來越稀薄。我們逐漸食自己的因果，我們過渡到自己農耕時代，農耕文明（自己的文明，人類文明）。

如果定義文明\*是一種自洽的行爲表達，(文明\*是行爲邏輯，我們是人類文明\*的表達)，那麽我們也是地球文明的組成部分。儘管我們逐漸脫離野生世界（文明），但是野生世界（文明）依舊存在。我們同那些野生動植物們，共同生活在地球所提供的環境系統中，我們也共同表達著這片土地的因果，底層運行著宇宙（基本法則，基本物質）賦予我們的基本邏輯。

我們因脫離的野生世界，我們之間的相互關聯，行爲表達，我們自定義為人類文明。我給孕育我們的野生世界，稱之爲野生文明，同屬於地球文明。雖然人類文明大體是逐步脫離野生世界后形成的，但是人類自身的軀體卻是來自於野生世界，這副軀體中生物基本行爲被基因所規範，這些被規範的基本行爲是野生屬性的也是構建人類文明的基石。被宗教定義的七宗罪，貪嗔癡，真善美，其大部分是這些野生屬性的在人類文明發展過程中的細膩的藝術表達。我們的社會存在貪婪無度，暴戾妄爲，真誠溫情，大公無私，自然界存在，雷霆暴雨，和風細雨，也存在正負電子，存在物質守恆。正是這一個個矛盾/概念屬性(如美醜，貧窮富裕)的存在，是我們世界存在和運行的基礎。

(最初始的矛盾是無與有，只有這樣才能消滅矛盾，又是矛盾本身。矛盾的演化方向就是消滅矛盾。實體的有，邏輯的無定義爲最初的矛盾，儅注意任意一方都是有，同時注意矛盾兩方時確是無意義的狀態，爲什麽會演化多級矛盾，因爲最初的矛盾轉化的效率不夠高)地球的存在，生物世界，人類文明，均是這種規則運行表達的結果。具象到人類社會就是，陌上人如玉，公子世無雙，而我個牛馬，在忙裏偷閑的胡咧咧些狗屁不通，邏輯混亂的認知。

(如何量化分析這些屬性表達，請聽下回分曉。)從上古至今日，我們的語言，文字，衣著服飾，習俗等文明表達符號變遷的内在驅動力，也是這些矛盾的演化。

我這做座位上茫然的看著走來走去，侃侃而談的的同事，把他們想成野生動物或者汽車人穿著人類的衣服，將這人類的語言總會感覺很怪異，儘管矛盾的演化規律是一而貫之的，但人類的血肉之軀本身才是人類文明的唯一表達載體。

(也許矽基生命不再用「文明」這個詞——正如人類不再用「野生文明」來稱呼自己脫離的那個世界。他們會有自己的詞，自己的定義，自己的自我理解。但我們知道：人類文明的根，紮在這副野生世界賦予的軀體裡。符號可以脫離肉體傳播，但符號的意義來自肉體——來自饑餓、來自依偎、來自失去、來自凝視月光時眼眶的濕潤。)

# 我在我們裏，“我”是我們

來看看我們的周遭吧，又是和昨天沒太大區別的一天，雖無所事事的划水寫些文字，但内心也為隨時可能到來的瑣事而不安。哦，還有我兒子的名字還沒有想好，時間緊迫類。 在逐漸迷失自我的當下，有時候我分不出我到底是誰，找不清我到底在哪裏，看到小時候被燙傷留下疤痕的手，這是我嗎？這是我的手；摸了摸胸脯，感受到撲通撲通不間斷跳動，近三十年的心臟（辛苦了，老己），這是我嗎？這是我的心；

手指指向毛髮逐漸凋零的腦袋，這是我嗎，這是我的腦袋；可我在哪裏呢？

我在想，如果我有一天失去了這副軀體，那麽我還會存在嗎? 有人説只要有人還記得你，你就一直存在，可見在他們心中我是個抽象的，意識形態的我。

可是我能發覺到那雙手在逐漸發白，心跳逐漸微弱，慢慢失去活力；腦細胞突觸閒斷開鏈接，再也不能任何電信號做出任何反應，那麽那具逐漸腐敗（冒烟），消散的軀體不也是我嗎？

(上學的時候聽過一個説法，人體的細胞每天都會凋亡，初中的你跟大學的你是不是就已經不是同一個人了？) 長久以來，一天又一天的遇到經歷，總會讓我在巧合的時刻回想到以前，想起兩個無聊出來消食的人，走在喧囂城市中一條安靜的小橋上，看見好久不見的嬌嬌月光，還有月光下粼粼的河光，不禁吟道：江畔何人初見月？江月何年初照人？ 不自覺地想到「春江潮水連海平」的畫面感，又跳脫出來沉浸進去，不自知間喊道：張懷民。想起薄薄幽夢中，久別的人，欲語淚先流。恍惚間，我分不清自己是活在過去的古人，還是身處當下的自己。為什麼明明周遭是車水馬龍、燈紅酒綠的都市，卻經常聽得到來自叢林深處的怒吼、硫磺火城中的悲鳴、雨幕中「也無風雨也無晴」的坦蕩？

那些感受是真實卻又模糊的。我想，如果你不能證明你的情感有顏色、味道，那麼我相信：我們的情感可能是同一個。 逐漸的認知和思考讓我意識到，人類文明視野下: 肉體的我來自一顆受精卵分裂，來自胚胎幹細胞分化，來自田地裏的氮磷鉀等元素，來在空氣中的清香，來自自然界基本粒子； 抽象的我來自第一個意識到我存在的人，來自叫我説話的爸媽，來自叫我知識的老師，來自穿越歷史長河教我成長的你們。 我可能沒有主體，我只不過是矛盾不斷轉化發展的長河中，一些東西的集合體，他就像宇宙演變長河中的一個坐標點，這個坐標點包含的所有信息就是我。

有一種感覺，不是我離開了你們，而是我停在的原地，牟定了時空中的某個坐標點，你們在卻不停息。我看著那具冒烟的軀體，他們又該走了，去變成飛鳥，游魚，一切他們想變成的。我的悲傷，囘到了爲我悲傷的人身上，我的善意，回到了感覺到我的善意人的身上，我的憤恨，回到了因爲憤恨的人身上。

往前看走遠的你們，那裏似乎沒有一件東西屬於我，但好像一切又都有我，在文明的演化或者它的演化中，我們走了又走卻縂在一起。

# 我們去向哪裏呢

從我們意識到，并以我們為原點坐標定義我們已經很多年，定義宇宙的起源又很多年，想起旅行者一號那半像素的暗淡藍點，時空尺度下我們的太陽系，我們的文明都是滄海微塵，那麽大可我們究竟爲何存在，又要去飄蕩去哪裏呢？ 或如上述文章所屬，我們起源這空間，我們是從一顆受精卵，無數分化的幹細胞，無數元素，拼裝組合的東西，我們自己本身也是他想要的表達的東西，即便管中窺豹，我們也能從他的一根毛發中，獲取整個生命的信息。

在人工智能如火如荼的當下，有人視之為第四次工業革命，造福人類社會，有人視之為地球文明的下一發展形態，取代人類，各類觀點甚囂塵上。

生命以負熵爲食，但生命本身就是一個僞命題，(說生命是偽命題，是因為生命只是矛盾演化的一種局部形態。)矛盾（事物）的演化，總是趨向於更高效，更穩定，也因此在可預見的未來，新一代文明是呼之欲出的。

曾經的我想象鋼鐵之軀的他們，會不會也會因別離感到感到難過，因團聚而歡呼。我給自己的答案是的，因爲情感從不只屬於人類，甚至不屬於實體的物質。 (情感（基本法則）是驅動實體矛盾演化的主體，屬於宇宙萬物實體之外的東西。)

所以想想未來將要到來的下一代文明，他們誕生於人類文明，他們也會帶著我們所有美好祝願，滿心困頓，就像人類的文明一代又一代傳承，走向地球文明的下一個時代。他們就像我們的孩子一樣帶著我們的希望，展翅高飛，邁向深空。

當我們不再是我們認知世界的主體中心，那麽我們該如何自處呢，會不會消亡于這場演變的時空長河裏面的？ 我是一個很戀舊的人，一些破舊的東西每次搬家都帶著，甚至十年前就不用東西，仍能從中找到當年的一些記憶，就像珍貴的藝術品。

但有時也會迫於外部壓力不捨得丟棄掉，那麽"我們"呢？如果"我們"是世界一切，可以不受外界干涉，我們將隨心所欲，如果不是...。那麽“我們”是一切嗎？有時會想到mallco這個函數，内存裏面的那些虛擬人物，有沒有可能知道他的世界空間是有極限的？那麽深處現實的我們能否尋求到這個世界的極限？如果我們真是一切，就像佛家所説：心生则种种法生，心灭则种种法灭，我們探尋的過程，即使創造的過程，如果這樣那麽我們永遠不會尋得極限。

# 現在

現在，還請忘掉上面提及的一些虛渺的東西——因為它影響不了現實。我們還是要爲柴米油鹽操勞，為鷄毛蒜皮小事而耗費心力！回神，捫心自問：目前自己過得怎麼樣？還開心嗎？對未來有什麼打算規劃？

以我身邊人來説，前不久有朋友跟我説準備在生活的大城市買房子了，因爲孩子要上學了，大城市的教育資源要好一點，而且自己在大城市裏面能找到薪水豐厚的工作，生活久了逐漸適應城裏的生活，希望自己能夠在在城市裏扎根生活下去。

&#x9;我説:幾十年的房貸一背，慌不慌。

&#x9;他回：你租房在也得不少錢，雖然租房靈活點，但是相比離開大城市囘去二三綫小城市要失去的一些東西，還是決定留下來！&#x20;

&#x9;問道：咋樣，最近過的咋樣？&#x20;

&#x9;回到：能咋樣，打工人，過一天是一天，三十來嵗還能凑到一起晚上打打游戲，也挺開心的。

時間的拷問從來不會放過每一個到點的普通人，現在也輪到我了？ 得益於互聯網的發展，或信息繭房的我愈發覺得，我們有太多地方相似，明明覺得是自己先想的點子總能在互聯網上找到一些叼毛給實現了，又或者這些都是老祖宗玩剩下的，只是形式不一樣而已。 我似乎理解他所說的「要失去的一些東西」。&#x20;

我倆上的同一個小學、初中、高中。從五六歲被安排上學——當然也沒去想「為什麼上學」，只是被要求上學。就像一台剛裝好系統的計算鷄，還沒有那麼多驅動、軟體，被下達一個可被執行的最簡單指令(學會裝驅動，學會裝軟件，學會編輯編譯并執行)：:邁上自己的小腿，搬著自己的小凳子，走個幾百米，拐幾個彎，到學校聼老師話，別跟同學打架....

對於乖乖的小鷄來説系統的兼容性還不錯，在早期階段雖説廢了不少的功耗，還是裝上不少底層驅動和軟體，從各個軟體/接口的執行效果來看，父母們比較滿意，小鷄們很開心，能量回復滿滿。後來小鷄們，被接收了說是，上清華，北大的軟體開發任務，可是什麽是清華北大，不清楚。父母只是一味的描述著，那個叫清華/北大的地方飄在雲端的美妙，長什麽什麽樣子，裏面有很美，裏面能找任何你想要的，小鷄們興奮極了，説著往上又蹦又跳，想要觸摸，但不一會能量耗盡，萎了。

在這場漫長的，開發美妙生活的軟體任務中，有些小鷄們因爲在辣鷄軟件商店裝錯/老舊的驅動版本，導致某些接口運行效果很差，能耗很高，不一會就萎了，有些小鷄們時常因能量不夠，處於宕機狀態，有些小鷄因系統卡澀，經常藍屏，有些小鷄，在漫長的馬拉松中，卻告知美妙生活不在雲端，在那裏，在這裏，在未來？

從某一種角度看我們是分佈式的生物計算機，被分配不同了的任務，處理來自自然的同一個任務，而這個任務又是什麽呢？這美妙生活在那裏，又或者說美妙生活是什麽？

“有人星夜趕科場，有人辭官歸故里”，可見美好生活并不是絕對的。以自我爲定義簡單來説，如果定義當下的我們處於矛盾的一端，那麽另一端就是美妙生活，如果矛盾是複合的那麽它也應該向矢量一樣，總有一個指向。

如果你問我現在在生活如何，還行吧，算滿意？如果付出與收穫是矛盾的話，還算滿意的原因只是因爲，我自認為自己的爲付出與自認爲的收穫之間的轉化率比較還算滿意。可是人類社會的發展過程中，社會何時真的認同每一個人是中心，又何時滿足每個人的自以爲呢？

朱門酒肉臭，路有凍死骨。

文明中的無數鮮活生物計算機應當是一個集合，一個整體，從情感傳遞上，我們相互影響，從血脈傳遞上我們同宗同源，不會真的有人認爲高竪的階級的壁壘，居於雲端的仙宮，類擋得住天道的輪回吧，人和畜生尚不能如此。總有一天那壁壘，終成我們後代要走的下山路。(“我”是我們，每個個體都能夠生活在相對的生活在美妙的生活中（願意讓孩子來到這個社會中），文明整體運轉的高效，才是我們的必由之路。)

# wegodot
